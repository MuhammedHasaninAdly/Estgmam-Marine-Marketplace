# ⛵ Estgmam (استجمام) - Marine Trip Booking Marketplace

A comprehensive digital marketplace and technical intermediary connecting marine service providers (Yacht Owners, Captains) with customers looking for marine experiences.

### ✨ Core Features

**👨‍💻 Customer Side (B2C):**
- Browse yachts and marine trips with dynamic filtering (auto-hiding sold-out trips).
- Detailed trip pages with `YachtMediaCarousel`.
- "Add to Favorites" functionality & seamless booking/checkout process.

**⚓ Captain/Provider Dashboard (B2B):**
- Public captain profiles showcasing available trips, ratings, and reviews.
- Secure dashboard for trip management, net earnings tracking, and financial settlements.
- KYC document uploads (National ID, Licenses) & bank account management.

### 🛠️ Tech Stack & Architecture

- **Framework:** Next.js (App Router) & TypeScript
- **Styling:** Tailwind CSS (with `animate-in`, `fade-in` transitions)
- **Database & Auth:** PostgreSQL hosted on Supabase (transaction/session poolers)
- **ORM:** Prisma (schema, migrations, seed scripts)
- **Payment Gateway:** Moyasar Integration (Mada, Visa, MasterCard, Apple Pay)
